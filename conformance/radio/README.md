# Radio circuits

A small AM receiver in three parts. Each part is a conformance test.

| ID | Circuit | Kind |
|----|---------|------|
| RAD-001 | LC tank, AC resonance | analytic |
| RAD-002 | Diode AM detector, transient | cross-tool |
| RAD-003 | Common-emitter audio stage, bias and gain | analytic |

Joined: antenna -> tank (001) -> detector (002) -> audio stage (003).
